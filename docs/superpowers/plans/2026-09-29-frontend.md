# Frontend Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** React UI for Dashboard, Item Hierarchy, Items, Parts and Sites on top of the Spring Boot REST API.

**Architecture:** Vite SPA. `api/` wraps fetch and maps ProblemDetail to `ApiError`; TanStack Query owns server state; table state (search/filters/page/size/sort) lives in the URL. Shared table/tree/form components; one page per screen. nginx serves the build and proxies `/api` to the backend.

**Tech Stack:** Vite 5, React 18, TypeScript 5, Tailwind CSS 3, React Router 6, TanStack Query 5, React Hook Form + Zod, lucide-react, Vitest + Testing Library.

**Spec:** `frontend/CLAUDE.md`, API contract in `backend/CLAUDE.md`.

## Global Constraints

- Types in `src/api/types.ts` mirror backend DTO records exactly.
- Empty values render as "—"; identifiers render as blue links.
- Page size options 25 / 50 / 100 (backend max 100).
- Dev: Vite proxies `/api` → `http://localhost:8080`. Docker: nginx proxies `/api` → `http://backend:8080`.
